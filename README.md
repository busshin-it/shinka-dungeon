# 進化ダンジョン

クラス進化・カード進化を軸にしたローグライク・デッキビルダーの試作です。

## 現在の目標
まずは「魔法師 vs スケルトン」の1戦を、横画面・スマホ対応・高品質イラスト素材で完成させます。

## アセット構成
- assets/backgrounds
- assets/characters
- assets/enemies
- assets/cards
- assets/effects

## 開発方針
UI文字や数値はHTML/CSSで描画し、AI画像はキャラクター・敵・背景・カードアート・エフェクトに限定します。


## GAME LAB 開発ログ
- 2026-10-03: PWA / fullscreen / landscape 対応。
- 2026-10-03: 山札・手札・捨て札の循環を実装。
- 2026-10-03: 戦闘後にカード進化 → 新カード3択 → 第2戦へ進む継続ループを実装。
- 検証仮説: 「戦闘で使ったカードが進化し、その結果を次戦ですぐ試せる」ことで再挑戦・成長実感が強くなるか。
- 次の検証: 第2戦の敵行動差別化、報酬カードのバランス、クラス進化への接続。

- 2026-10-03: 3部屋の短い1ランを実装。第2戦は通常攻撃/呪詛の交互行動、第3戦は3手パターンを持つ敵として差別化。
- 2026-10-03: 戦闘間にダンジョンマップを追加し、「進化 → 報酬 → 次戦で試す」を3戦連続で確認できる形にした。
- 現在の検証点: 敵の次行動を見て手札を選ぶ判断が生まれるか、進化・報酬を次戦ですぐ試すことが「もう1戦」につながるか。
