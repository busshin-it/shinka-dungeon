### 新6系統の専用モード（既存の敵6戦・実験段階）

- [3戦の独立試作](v4-1/six-paths-pilot.html)（従来の効果試作）
- [本編の敵と6戦する実験モード](v4-1/six-paths-pilot.html?mode=legacy-enemies)（GitHub Pagesで試遊可能）

6戦モードは、既存の `planning-engine.js` を**読み取り専用の敵データ提供元**として読み込み、`GROWTH_ENEMIES` / `CURRENT_ENEMIES` から6体の名前・HP・行動パターン・一撃/合計/攻撃枚数による詠唱弱体化を試作用エンジンに渡します（`six-paths-enemy-bridge.mjs`）。カード効果・4択報酬・保存は新6系統の専用処理です。従来のルート選択や旧61種のカード、旧セーブを一緒に持ち込むものではありません。元の敵データに物理/魔法耐性属性がないため、実験側は敵耐性0%・敵攻撃種別未分類とし、未定の仕様を元データにあるかのようには扱いません。

モード専用の保存キー（`shinka-six-paths-legacy-enemies-v1`）により3戦試作（`shinka-six-paths-journey-v1`）・従来の配布版から分離しています。**本編の署名済み配布ファイル、サービスワーカー、保存スキーマは不変**。絵は未対応。試遊専用ページとして公開済み。ブラウザ実機試遊はまだ行っていません。

### 12戦の長い冒険（新6体追加・開発版）

[**12戦の新カード試遊版をブラウザで遊ぶ**](https://busshin-it.github.io/shinka-dungeon/v4-1/six-paths-pilot.html?mode=long-journey)（本編と別の公開ページ）

カードを集める前に6戦が終わってしまう課題を検証するため、敵を**既存6体＋仮設計の新敵6体＝計12体**に拡張した独立モードを設けました。新敵は「霧道の盗賊」「苔の守り手」「灰鎧の槍兵」「凍星の舞姫」「影綴りの術士」「鐘楼の護衛」で、攻撃回数、非攻撃ターン、回復、攻撃閾値、物理・魔法耐性などの組み合わせを変えています。敵の新しい名前/HP/耐性は**試作値**で、既存本編の敵には追加していません。

12戦では初期10枚から始め、**各戦後に4択・見送り可、最終戦を除いて最大11回カード取得**できます。すべて取るとデッキは21枚。獲得したカードは次戦の初手で試せます。画面にデッキ枚数・獲得枚数を表示し、12戦専用の保存キー `shinka-six-paths-long-journey-v1` に自動保存します。従来3戦・6戦の保存は読み書きしません。

段階的な試作のみです。敵の難易度曲線、長編のカード獲得ペース、12戦完走率、人間が感じる楽しさ、実機の操作、正式な本編への採用は**未検証**。イラスト、本編エンジン・旧セーブ・配布メタデータは変更していません。

**公開履歴:** 2026-10-09、PR #31 の追加ファイルだけを main にマージし、[GitHub Pages](https://busshin-it.github.io/shinka-dungeon/) へのデプロイは成功。既存ゲームのコード・保存・配布メタデータは未変更。ブラウザでの人間による試遊とゲームバランスの評価はこれから。

### 12戦・護符と初期手札を選んで始める（試作）

[護符と初期手札を選ぶ試作](v4-1/six-paths-pilot.html?mode=long-journey&pace=quick&setup=forge)

テンポ重視12戦の**専用の新しい開始方法**。まず護符8種類から毎回ランダムに提示される4候補のうち1つを選びます。護符は戦闘開始ごとに発動（魔力+1、鏡術防御4、氷弱体3、毒2、魔狼/ゴーレム召喚、通常防御5、初手6枚の8系統）。次に、4段階のカード選択で毎回ランダム3候補から1枚ずつ選びます。**選んだ4枚＋必ず魔弾1枚が第1戦の最初の5枚**となり、残りの5枚と合わせて10枚デッキです。選択後は通常と同じ12戦・各勝利後の4択報酬を遊べます。

護符の新名称と効果数値は検証用の仮仕様です。初期手札の選択には攻撃・防御・属性・召喚などの分類を用意し、勝敗よりもカードの組み合わせを試すことを重視。**従来のカード進化画面を移植したものではありません。** この開始方法だけ別の保存キー `shinka-six-paths-quick-forge-v1` を使い、旧3/6/12戦および既存本編の途中データは変更しません。
