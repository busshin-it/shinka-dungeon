# B1 第51歩｜雷の連鎖と結界デッキ（試験実装）

2026-10-13。ユーザーから「雷系は低コスト・低威力だが連続使用で強く」「シールドを重ねて反射・竜育成・毒／呪いと相性よく」と指定。試験実装は既存の57カードを壊さず **雷4＋結界4の8枚** を追加し、合計65種類とする。

## 雷連鎖のルール
- **同じターン中に雷属性のカードを連続使用する**と、2枚目から直前の雷使用回数×2ダメージ（上限＋8）が付く。ダメージは対象への1ヒットごとに加算。範囲雷なら各敵への基礎威力に加算する。
- 途中で雷以外を使うと連鎖がゼロに戻る。ターン終了でもリセット。手札を引くだけの導電も雷を使用した回数として数えるが、導電自体は攻撃しない。
- 従来の雷撃・雷針・双雷槍・天雷・双雷・連鎖雷・破魔雷・雷の奔流も雷連鎖属性を持つ。従来のダメージ・コスト・既存「先に攻撃していれば＋6」はそのまま。長く連鎖させた場合だけ威力が上乗せされる。
- 初期の低コストカード：**雷光（0/2ダメージ）／跳雷（1/3×2）／雷の環（1/全体2）／導電（1/2枚ドロー）**。
- 強化版：雷光4、跳雷5×2、雷の環全体4、導電3枚ドロー。現行の魔力・攻撃上昇との加算は従来ルール。
- 雷連鎖の回数を主人公の状態効果へ表示する。

## 結界・防御のルール
- **小結界（0/防御3→強化で5）**：防御の土台、0コストでも手札1枚を消費する。
- **反響結界（1/防御5、反射3→強化で防御7、反射4）**：そのターンの敵攻撃を防御で1以上受け止めたとき、実際に防いだ攻撃者へ反射。複数の敵が攻撃した場合はそれぞれに反射が働く。防御できなければ反射は発動しない。毒や破盾で防御無視されても反射しない。反射の備えは敵ターン後に消える。
- **封毒の盾（1/防御4、毒・呪いが付いた敵が1体以上なら＋3 → 強化で基本防御6）**：毒や呪いの仕込みをしてから防御し、継続ダメージが入るまで耐えられる。
- **育竜の護り（1/防御6→強化で8）**：竜を召喚済みで、このカード使用後の防御が10以上なら竜を1段階成長。竜がいなければ通常の防御として使用できる。1枚の使用で条件判定は1回。
- 敵の毒・呪い処理と竜の進化時攻撃は従来のまま。結界を重ねれば強くなるが、状態異常を先に付与する手数・防御を積む手数が必要。

## 入手と表示
- 新8種すべてを戦闘ごとの報酬候補に配置。3枚から1枚を選ぶ仕組みは不変。
- 新規の画像生成・画像差し替えは行わない。**今回の8枚のイラストは既存の雷・氷盾・毒・魔法の原画を仮再利用する**。カード効果・イラスト固有化は後続作業として分離。
- 既存の承認済みカード枠は全65枚で使う。旧画面・保存形式を破壊せず、新しい状態は戦闘内だけに保持する。
- 報酬入手可能性は基本5を除く計60/65種。竜は直前の仕様どおり、卵所持時に餌・竜息が候補となる。

## テスト・保護条件
- 基本数値・既存の攻撃計算、最終ボス・竜育成・毒呪い、フリーズ対策、手札使用とプレビュー、報酬3択・旧版は不変。
- `tests/astral-underground-b1-lightning-shield.test.mjs` は連続雷の実ダメージ、他系統を挟むとリセット、敵の攻撃に対する反射、毒・呪い中の防御、竜育成、防御カードの強化などをチェック。
- GitHub CIとユーザーの画面・プレイテストは区別。火力や防御の数値は仮のバランスで調整可能。
