# B1 第48歩｜進化画面のスクロール根本修正と報酬カードの範囲確認

記録：2026-10-13。ユーザーから「スクロールまだおかしい。全種類が報酬ででる？」という報告・質問。

## 1. スクロールの問題

過去のPR #113〜114で全画面／一覧のスクロール位置を複数回調整したものの、CSSの `.b1-evolution-choice > .pilot-card-copy` に `overflow:auto` が残っていた。カード一覧に何枚もあるカードそれぞれが**別個のスクロール領域**になり、マウスをカード上に置いてホイールを動かすと、候補一覧の代わりにカード内部のスクロールが反応し得た。

対応：
- 進化画面の唯一の縦スクロールは `#restUpgradeCards`。
- 進化カード自体は `height:auto` で長文に合わせて伸び、本文を `overflow:visible` にして内部スクロールをなくす。画像の高さは `clamp()` の一定範囲を用い、カード全体を伸ばしても絵と効果を保持する。
- `#restUpgradeCards` の `wheel` を受け取ったら、`deltaMode` を考慮してスクロールを明示的にリストへ反映。リストの末端でも背景へwheelが伝播しないよう `preventDefault()`。
- 手札のマウス操作・ドラッグ、勝利報酬、カードの効果・強化処理・保存は変更なし。
- `tests/astral-underground-b1-upgrade-scroll-wheel.test.mjs` でレイアウト規則・イベントコード・JS構文を検査。**このテストは実機ブラウザ操作の証明ではない**。ユーザー側で再確認が必要。

## 2. 報酬カードは本当に全種類か？

**いいえ。現在、カード定義は57種類、そのうち勝利後の報酬候補に少なくとも1度含まれるのは44種類。13種類は報酬に登場しない。**

コード正本：`v4-1/underground-b1-engine.mjs` の `CARDS` と `STAGES`。`STAGES` は12戦。第1〜11戦には各9枚の固定候補リストがあり、勝利時にその9枚をシャッフルして3枚抽選する。`s.rewards=shuffle([...STAGES[s.stage].rewards]).slice(0,3)`。ボスの第12戦は報酬なし。

報酬に含まれない13種：

| 入手分類 | ID | カード |
|---|---|---|
| 初期の基本カード | `basicAttack`, `basicDefense`, `bolt`, `guard`, `break` | 攻撃・防御・魔弾・守り・崩し |
| 商店で購入できる5種 | `fireSmall`, `fireMedium`, `fireLarge`, `darkBolt`, `doping` | 単体火の魔法 小・中・大、闇弾、ドーピング |
| 竜開始デッキ限定 | `dragonEgg`, `dragonFeed`, `dragonBreath` | 竜の卵・竜の餌・竜息 |

注：上記は勝利報酬リストへの掲載有無の分類であり、カードの現在の入手経路を簡単に示したもの。選択可能な初期デッキ・商店にも特有のルールがある。

**報酬プールは今回変更しない。** 全57種を毎回抽選対象にすると、基本札が貴重な報酬を埋めたり、竜を選んでいないプレイヤーに竜の餌だけが出る問題が生じ得る。通常の報酬候補を44→49種にするか、竜は竜デッキ用に限定するかをゲーム設計として別途決める。
