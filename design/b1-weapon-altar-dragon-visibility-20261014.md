# B1 竜の配置・武器選択の表示修正（2026-10-14）

## 再現と原因
- 実機で竜の立ち絵が手札付近（主人公と敵の間）の中央を隠す。元の CSS `underground-b1-dragon-visuals.css` は左39%・下9%で、スマホ専用設定も左38%・下6%。育成やダメージ処理ではなく、表示位置の問題。
- 第4戦後の武器祭壇では、カード上部の数ピクセルしか見えず、候補名と効果が読めない。原因は `#weaponSite` の flex 子要素 `#weaponChoices` に高さ0を許すのに、親 `.pilot-overlay-window` が flex レイアウト／明示高さを持たず、候補の領域がゼロ近くまで縮められる構造。

## 対応
1. `#journeyPanel` に選択画面だけの `b1-weapon-open` クラスを付与。閉じたら自動解除。既存のカード報酬・休憩・商店へは適用しない。
2. 武器選択画面は viewport 内で明示的な高さを持ち、縦flexでタイトル／ヒント／候補3枚／見送りを配分する。3候補は横1列3カラムの grid で、余った縦幅を受け取る。個々のカードのmin-heightを0にしてスクロールなしで収める。短い横画面は文字と余白を詰め、縦持ちは3件縦スクロールも許可。
3. 最後に読み込まれる `underground-b1-phone-hand-visibility.css` に竜の表示位置を限定して上書き。左上側・上寄り・小型にし、手札と敵の意図欄を避ける。画像・段階表示・ドラゴンの当たり判定／成長計算は維持する。
4. アプリ内更新表示と `b1-release.json` を `2026.10.14.6` に揃える。

## 影響と確認境界
- 対象はB1の見た目だけ。85枚カード、武器効果、敵、HP、報酬、セーブ情報、旧本編、PCの別ページは変えない。
- 既存の武器3択・見送りイベントと竜の描画更新をテストで維持。CI合格とAndroid実機での文字表示は**別**。実機では「3枚同時に見える／武器名・効果が読める／見送りが押せる」「竜が手札・攻撃予告を覆わない」を確認。
- 元に戻すときは本修正PRをrevert。画面遷移・ゲーム状態を変更しないためデータ移行不要。
