## 現在地と今回の範囲

GitHub main `fc157e7e14b789d34940394ef56a2415f116fba2`、公開済みV4.25・61種を基準とした。AGENTS指定のMD、最新ログ、制作手順、全カード・報酬・テストを確認。戦士は設計のみで、今回も現行魔法師の小型セットに限定する。

## なぜ総数61枚でも同じカードになるか

- 初期デッキは魔弾5・守り5。第1戦の固定初手・魔力経済・敵は同じで、基本札の割合が高い。
- 前回の3択化では初回10種類、次13種類に制限した。全体のカード数と、実際に序盤で選べる種類には大きな差があった。
- 役割ごとの候補が少なく、敵の違いがあっても同じ選択を引きやすい。霜の護符では氷の矢が優勢という前回の小量比較も残る。

**発見／失敗**：総カード枚数や提示3枚だけを指標にしても、ランごとの違いは評価できない。選びやすさを優先して候補を絞りすぎた。候補の種類・出現位置・基本札から使える関係を合わせて見る。

## イラスト

各カードに独立artキーを設定し、既存のプロジェクト画像4点を無変更で再利用。新しい専用絵の生成やFactoryジョブはなし。画像元は1点ずつ目視確認し、manifestへhash・由来・確認範囲を記録。再利用元には以前の描画方針の絵も含むため、新規ゴシック・シルエット風パペットの完成素材とは扱わない。専用絵への差替えは別バッチ。
