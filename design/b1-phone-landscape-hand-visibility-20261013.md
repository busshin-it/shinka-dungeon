# B1 Android横画面｜ヘッダー撤去と手札全体の表示（2026-10-13）

## 発端
ユーザーのAndroid横画面スクリーンショットで、上のゲーム名／図鑑／最初から／メニューの帯は不要で、手札の下半分が見切れていた。

## 原因と対応
- underground-b1-reward-shop-status.css に後段で定義された body.pilot-mode #playScreen の --b1-hand-dock:clamp(155px,36dvh,215px) が、B1の手札を大きくするほかのCSSの値より優先していた。
- B1専用の underground-b1-phone-hand-visibility.css をCSSの最後に読み込み、横向き／幅1100px以下／高さ620px以下に限定して適用。
- 上のヘッダーと重複する進捗行を非表示。戦闘面に縦空間を戻す。戦闘中の名前・HP・敵の予告は従来どおり残す。
- 手札領域を clamp(184px,57dvh,246px) に拡大。手札の横移動・タップ・ドラッグを保持。
- 隠れる図鑑／最初からは、ターン終了横の小型「⋯」メニューから同じ処理を呼び出す。やり直し確認も保持。
- 高さ305px以下では従来のスクロール逃げ道を維持。縦持ち／PC画面／他モードは変更しない。

## 検証と未確認
- 自動テストでは最終CSS読み順・手札面積・メニュー操作の構文・極小画面の逃げ道を監査。
- ゲームエンジン・保存データ・77枚のカード・敵AI／報酬／強化には変更なし。
- GitHub CI／main統合／Pages配布／Android実機での見た目と操作は別々に確認する。実機の最終見た目は未確認。
- 戻す場合はUI限定PRをrevert。原画やゲームロジックは元のまま。
## 実機写真による再修正（2026-10-13、PR作業中）
- ユーザーが再送した写真2枚で、ヘッダー非表示は反映されている一方、戦闘の手札は絵だけが目立ち、名前・効果欄の下部が画面外となることを確認。休憩所の強化画面は候補が横長1列で、余白に対して候補の表示が低かった。
- 小さなCSS値変更ではなく、B1横画面の手札の縦サイズを画面高64%（最小190／最大300 CSS px）へ増やし、カード内の絵を54%に抑えて名前と効果の領域を確保。ナビゲーションバー手前に余白を追加。
- 休憩所の強化候補は横幅740 CSS px以上で2列、狭い画面は1列。候補カード高さを205 CSS px以上、上部説明をたたんで強化前後を読める領域を拡大。スクロールは候補一覧に限定。
- 表示に問題を起こしたCSSの競合を含め、画面実寸での最終確認が必要。変更前に戻す場合はこの追加PRだけをrevertする。
