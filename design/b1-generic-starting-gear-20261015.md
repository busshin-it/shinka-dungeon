# B1｜汎用初期装備8種類・戦略を固定しない導入（2026-10-15）

## 目的と方針
開始時に雷・竜・物理・反射専用装備を選ぶと、序盤から拾うべきカードが決まりすぎる。カードと報酬の偶然から戦術を発見する体験を優先する。

- 15階層モードの冒険開始時に、下記の汎用装備8種類から**seedで確定する3候補**を提示し、1つだけ選ぶ。
- 既存のカード3択×3回は再導入しない。デッキは既存の基本デッキのまま開始。
- 専門装備4種（雷導の杖・古木の棍棒・月鏡の杖・竜骨の杖）は**中盤の宝箱報酬の候補として維持**。取得時には開始時の汎用装備から交換される。
- 相性表示は既存の専門装備にだけ付ける。汎用装備だから雷・毒・竜が選ばれやすくなる、という隠し補正を入れない。
- 既存12戦モード・カードの数値・敵の強さ・商店価格・報酬候補の確率は変更しない。保存キー／保存形式は維持し、旧4武器を装備したセーブも復元可能にする。

## 新規汎用装備（試作数値）

| 名称 | ID | 効果 | 特徴 |
|---|---|---|---|
| 旅の小盾 | `travelShield` | 戦闘開始時に防御4 | 守るカードが少なくても役立つ |
| 星読みの手帳 | `openJournal` | 戦闘開始時に1枚追加ドロー | 高コスト・低コストいずれも選べる |
| 時の砂時計 | `hourglass` | 2ターン目に魔力＋1 | 2ターン目の行動幅 |
| 調律の鈴 | `rhythmBell` | 毎ターン3枚目のカードで1枚引く | 属性に関係なく、枚数を組み立てる |
| 旅人の護符 | `travelPendant` | 毎ターン最初にカードを使うと防御＋2 | すべてのカード種別で発動 |
| 夜明けの石 | `dawnStone` | 戦闘開始の1ターン目に魔力＋1 | 初動を少し広げる |
| 旅の革袋 | `coinPurse` | ボス以外の戦闘勝利で金貨＋10G | 商店の使い方が変わる |
| 薬草のお守り | `herbAmulet` | ボス以外の勝利後、通常回復＋2 | 長期的なHP維持 |

数値は**初期試作**。特定装備が常に最良にならないか、総与ダメージ・手札・残HP・勝率・1戦の所要時間で評価する。勝率調整そのものは今回対象外。

## 実装位置と安全境界
- `v4-1/underground-b1-engine.mjs`：汎用装備IDと発動処理。汎用装備は通常の戦闘ルールの条件分岐のみ使用する。
- `v4-1/underground-b1-journey.html`：画面には3つだけ表示し、選択で1階へ。
- 専門装備4種と`getB1WeaponOffers`はそのまま残す。旧セーブの`weaponId`参照に対応。
- 旧カードスターター選択処理はテスト・互換用として残すが、15階層の通常UIからは使用しない。
- 問題があればこのPRをrevert。ユーザーの保存データや旧装備定義は消去しない。
