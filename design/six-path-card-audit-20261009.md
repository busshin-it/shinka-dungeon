## 3. 役割の重複を減らす4つのポイント（検討案）

1. **①攻撃呪文 vs ③剣闘士**：攻撃回数だけを両者の強みとしない。①は呪文の属性や手札/魔力と連動、③は物理の連撃・魔法を捨てることで成立する別の判断を中心にする。物理フラグを導入するまでは既存カードを純物理と扱わない。
2. **③背水 vs ⑤超火力**：③は「HPが低い状態で継続して戦う剣技」、⑤は「その一撃のために防御・状態・HP・情報などを支払う大呪文」。⑤にも低HP補正は可能だが中核にすると重複しやすい。
3. **④結界 vs ⑥ゴーレム**：④はブロックや反射自体の作成/消費、⑥は最初の対象防御カードを1ターン1回強化する「戦闘中の交換可能な相棒」。維持中は魔力上限-1という負担がある。
4. **②状態異常 vs ⑥炎の精霊**：②は状態異常を付ける/蓄積/使い切る、⑥は呪文使用時に火傷を載せる「入口」。火傷は未実装なので先行設計と実装済みは分ける。

## 4. 既存コードの効果だけで成立するコンボ（例）

| 使用順 | 現在の効果と判断 |
|---|---|
| `霜の輪` → `霜穿ち` | 霜の輪の弱体4により、霜穿ちの「弱体3以上で+7ダメージ」条件が成立。弱体をあえて消費しない選択に意味がある |
| `鏡の結界` → `鏡頁の槍` | 反射を貯めて、後者で反射を全消費しダメージへ。敵の攻撃への備えを残すか攻めへ転換するか選ぶ |
| `薄い守り` → `鏡撃` | 先にブロックを得て、その一部を攻撃へ転換（鏡撃はブロックを全消費）。敵のIntent次第で弱くもなる |
| `蓄電` → `天頂の雷` | 蓄電が魔力+1。天頂の雷は**使用前の魔力4以上**でボーナス+6。魔力を温存して達成するか、すぐ使うかが争点 |

## 5. 新規の系統をまたぐコンボ（完全に設計案、未実装）

| つながる系統 | 2〜3枚の試案 | 面白さ／弱い条件 |
|---|---|---|
| ①×⑥ | 魔狼召喚 → 闇弾 | 闇弾でドローしつつ魔狼の初回追撃。魔力上限-1は高コスト呪文と相性が悪い |
| ②×⑥ | 炎の精霊召喚 → 呪文 → 火傷を活かす札 | 毎ターン最初の呪文が状態異常の種になる。火傷が未実装で、具体的な消費札も未決定 |
| ③×② | 魔剣の氷付与 → 物理追撃 | 呪文と物理の使い分け。既存カードの物理判定はない |
| ④×⑥ | ゴーレム召喚 → 光壁 | 光壁による防御と魔獣の追加防御。召喚維持で魔力上限を拘束するため、長期戦でのみ有利とも限らない |
| ⑤×⑥ | 魔獣維持 → 生贄の儀 → 高コストの呪文 | 生贄で魔力枠が開くが、**魔力そのものを補充するかは未決定**。魔力消費合計を必ず計算する |

## 6. 敵によって正解が変わるかを試す例

- 多段攻撃の `鏡の亡霊` では、弱体・反射の小さな効果が繰り返し効く。
- 高ダメージの詠唱を構える `星弓の番人` では、**単体の手札攻撃12以上**で詠唱を崩せるため、大きな一撃に意味がある。
- 攻撃しないターンがある `蒼鎧の門番` では、次の強打の準備や魔力の持ち越しにも意味が生まれる。

したがって、新カードは単にダメージ効率だけでなく、敵の行動・現在HP・魔力・次ターン・護符で評価する。
