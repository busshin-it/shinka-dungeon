# B1 武器4種類の発動演出と状態表示（2026-10-14）

## ゴール
武器を装備しても、その効果がいつ使えるか分からなかった。戦闘中のHP表示近くにコンパクトな武器の状態を出し、**実際に装備効果が発動した瞬間にだけ**短く光って追加効果を表示する。

## 実装
- エンジンで武器の発動処理の直後に `weaponActivation`（連番、武器ID、実際の効果説明）を記録。今までの戦闘ログと補正値はそのまま。
- `snapshot().weaponStatus` は戦闘内の現状から導く：
  - 雷導の杖：雷連鎖0/3、1/3、2/3、3枚目使用済みを表示。攻撃カードが3枚目でなければ発動しない。
  - 古木の棍棒：毎ターンの最初の物理攻撃＋3がまだ使えるか、使用済みか。
  - 月鏡の杖：敵の攻撃を実際に防いで2反射するまで待機、発動後はそのターン使用済み。次の味方ターンでは再び発動可能。
  - 竜骨の杖：卵未召喚／竜育成中。初回の卵召喚は発動扱いにせず、実際に竜が成長した場合のみ防御＋3の通知。
- UIは `hero-hud` に小型の「武器名・残り条件」の表示、ステージ上に17百ミリ秒の一時的な「発動！」通知。連番が増えたときだけ表示し、再描画で同じ演出が重複しない。ゲーム再スタート時はタイマーもリセット。
- スマホ横向きは短い名前・効果状態で見切れない幅へ圧縮、敵の予告・手札に干渉しない。 `prefers-reduced-motion` に従ってアニメーションを省略。画面読み上げ用のlive領域を用意。
- CSS追加は `underground-b1-weapon-feedback.css` のみ。画面の他のカードサイズや枠線、武器画像やプレビューは変更しない。

## 保護と確認
- 装備ボーナス・実ダメージ・防御・反射・カード85種類・12戦・報酬抽選・保存・新旧ゲームの戦術ルールは不変。テストで4武器の正しい発火／不発火、戦闘結果、表示用の連番とHTML/CSSを検証。
- GitHub Actionsの成功と実機Androidでの「読める・邪魔しない」は別確認。武器未所持なら表示は出ない。実機で誤発動表示や画面を覆う問題があれば、このPRをrevert。
- 画像生成は行わず、既存素材を維持。アプリ表示番号を `2026.10.14.9` に更新。
