# B1 第46歩｜拡大カード・強化画面スクロール・敵モンスター統一

記録日：2026-10-13。対象：`busshin-it/shinka-dungeon` の独立B1。

## ユーザー報告
- 手札のカードがアップにならない（hover・選択時の拡大が手札と同じ大きさ）。
- 進化するカード一覧を下にスクロールできない。
- 敵に人間キャラクターが登場するため、**敵はモンスターのみ**にしたい。

## 修正
1. **拡大表示**：もとの224px上限は通常手札190～230pxとほぼ同じだった。拡大コピーを最大幅390px・画面幅82%・高さ78%以内で可変表示する。PCはhoverで表示、クリックでカード選択、タッチは既存の選択/ホールド機構を維持。魔力が不足していてもカード説明を確認できる。ドラッグ判定と使用判定は元のコードを継続。
2. **進化一覧**：以前は固定高さのflex階層に `overflow:hidden` と内部 `height:100%` が重なり、画面下にある候補へ到達できない端末があった。進化画面のウィンドウを**唯一の縦スクロール領域**とし、内部の選択グリッドは実際の全カード枚数に応じて伸びるようにする。touch-action:pan-y、スクロール末尾の戻る操作を維持。進化前後の効果・カード能力・選択ロジックは不変。
3. **敵はモンスターのみ**：人間の立ち絵 `librarian-noa.webp`（治療師）、`gatekeeper.webp`、`bow-watcher.webp`、`tide-star-sentinel.webp` をB1敵の描画マップから除外。現在ある怪物／精霊素材 `bell-spirit.webp`、`wraith.webp` と最終ボス専用の `boss.webp` を使用。敵の表示名も呪霊・針獣・毒胞獣・癒し胞子などへ変更し、人間の称号を使わない。
4. **未制作の専用原画は勝手に生成しない**：各敵固有の高品質なモンスター素材は別途制作する。今回は既存素材を再利用するため、**異なる敵が同じ立ち絵になる場合がある**。戦闘上の敵ID・role・HP・予告・AI・ターン・報酬・保存・12戦は不変。

## 保護条件と確認
- カード57種類の効果と共通フレームはそのまま。
- カードをクリックして選ぶ、敵へドラッグして発動する、横にスクロールする、強化選択する、キャンセルする操作は壊さない。
- `tests/astral-underground-b1-zoom-scroll-monsters.test.mjs` の実装意図テストと既存の `astral-*.test.mjs` を確認。
- CIが成功しても、Windows PC・Androidなど実画面の挙動は別確認。とくに低い画面で拡大カードと進化画面のスクロールを点検する。
