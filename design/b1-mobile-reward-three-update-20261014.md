# B1 Android・スマホUI（2026-10-14）: 報酬3枚横並び／設定から手動更新／装飾線を整理

## 実機の声
- ユーザーは勝利報酬を縦一覧ではなく「横に3枚」、できる限り下スクロールなしで比較したい。
- インストール済みアプリで変更が見分けにくい。右側の「⋯」設定に最新版を確認／更新するボタンと版番号が欲しい。
- 手札カードの細い装飾線が重なって見づらい。スマホ版のみ減らす。

## 変更
1. 最終B1モバイルCSSだけで、**スマホ横向き（幅1100px／高さ620px以下）**の勝利報酬を1画面3列へ。上部のイラスト35％、下にカード名と効果原文を普通の文字配置で表示。縦スクロールを使わず、見送り操作も維持。高さ365px以下ではイラスト比率を27％まで圧縮。縦持ち表示は以前の縦一覧を残す。
2. 戦闘中の手札カード本体の二重・三重装飾線と角の装飾疑似要素だけ、スマホで非表示。1本の控えめな輪郭と選択中の視覚フィードバックは残す。イラスト、コスト、種類、名前、効果、ドラッグ機能はそのまま。
3. スマホの「⋯」メニューに「最新版に更新」ボタンと「表示中」の版番号を追加。`b1-release.json` を毎回ネットワークから確認し、再読み込み前に**今のプレイの進行が失われる可能性**を確認。承認時のみユニークなクエリ付きでページを再取得。SWの登録・更新／ユーザーデータ・キャッシュの削除は行わない。
4. **次回以降のB1公開更新時**：`v4-1/b1-release.json` の `build`、`v4-1/b1-update.mjs` の `B1_BUILD`、ページ `data-b1-build` の3つを同じ番号へ更新すること。これを怠ると差分検知の精度が失われる。操作は常に確認付きで再読み込みできる。

## 保護・確認
85種のカード効果、戦闘、報酬抽選3択、保存／旧本編、既存原画を触らない。PCは従来の大型3列を維持。CSSのみの見た目が端末上でどう見えるかは、CIとは別に確認する。特に効果文が長い場合は、通常の横向きスマホの高さで読めるかを実機で確認する。
