# B1・カード報酬／商店／状態表示の見直し（2026-10-13）

対象：ユーザーの実画面3枚。PR #102（main統合：`2c4b2f3`）。

## 目的と仕様
1. **報酬の絵が上端の細い帯に見える問題**：旧B1の70pxアート指定をB1限定CSSで上書きし、報酬画像は高さ58%、本文は独立領域。表示高に収まらない場合はオーバーレイをスクロール。スマホ横長の高さ不足にも個別対応。
2. **商店**：今まで表示されていた全価格カタログから、入店時に「3枚だけ」を抽選する方式に変更。毎回3種類・重複なし。同一来店中は購入や描画更新後も同じ顔ぶれ。ランダムの再現性はゲームシード＋ステージで固定し、戦闘乱数・報酬乱数には影響を与えない。UIに表示した3枚以外はbuyShop APIでも購入不可。全カードと価格は別の `shopCatalog` で保持し、`shopStock` は当日の3件だけを意味する。
3. **商店の見た目と削除**：購入候補・30G削除一覧をゲームの `cardButton()` と共通画像描画・画像欠落時CSS代替で表示。カード名・効果・価格の確認性を維持。削除は既存のインデックス指定・残金不足禁止・一回のみというルールを保持。
4. **状態効果**：味方、敵1体、複数敵の各キャラ上部へ防御・攻撃上昇・毒・弱体・脆弱・混乱・幻覚・呪い・ドロー上昇などの短い絵文字アイコン＋数値を表示。説明はtitleとaria-labelから確認可能。古いステージのキャラDOMをそのまま保護し、アイコンをB1起動時に付加する。
